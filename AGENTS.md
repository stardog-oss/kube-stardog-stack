# Project-wide agent guidelines

These guidelines apply to the entire repository, including all charts, documentation, tests, and release artifacts.

## Jira tickets

- References matching `SAT-<number>` (for example, `SAT-894`) identify Jira tickets.
- Read the referenced ticket and its available requirements, acceptance criteria, and comments before planning or implementing the work.
- Do not use GitHub issues or pull requests as the primary lookup for a `SAT-*` ticket. GitHub references may provide supporting implementation context after reading Jira.
- If the ticket cannot be accessed, report the specific blocker and request the missing ticket content.

## Communication

- Do not use em dashes in responses.
- Give rigorous, objective feedback. Avoid reflexive compliments; base positive assessments on demonstrable merit.
